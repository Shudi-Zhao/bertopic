# BERTopic Learning Repository 📚

## 🚀 Overview
This repository is a **learning process** using Python to run all the code from this **BERTopic** tutorial:  
[Best Practices for BERTopic](https://maartengr.github.io/BERTopic/getting_started/best_practices/best_practices.html), a versatile topic modeling technique that leverages transformers and c-TF-IDF to create dense clusters, resulting in easily interpretable topics. Our objective is to explore various functionalities of BERTopic, including its modular components and diverse applications.


---

## 📌 What This Repository Covers

- **Installation**: Step-by-step instructions to install BERTopic and its dependencies.

- **Quick Start**: Guidelines on extracting topics from datasets, such as the 20 newsgroups dataset, using BERTopic.

- **Fine-tuning Topic Representations**: Techniques to enhance topic representations for improved coherence and interpretability.

- **Modularity**: Insights into BERTopic's modular design, allowing customization of embedding models, dimensionality reduction techniques, clustering algorithms, and vectorizers.

- **Overview**:
  - **Common**: General concepts and functionalities of BERTopic.
  - **Attributes**: Detailed descriptions of BERTopic's attributes and parameters.
  - **Variations**: Different approaches and extensions of BERTopic for specialized use cases.
  - **Visualizations**: Methods to visualize topics, hierarchies, and distributions for better analysis. 

- **Citation**: Information on how to cite BERTopic in academic and professional contexts.
